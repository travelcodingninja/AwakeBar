# AwakeBar

AwakeBar is a lightweight macOS utility for user-controlled display wakefulness sessions.

It helps keep the display available during presentations, focus sessions, monitoring tasks, streaming, and reduced-interaction workflows. AwakeBar uses a standard macOS display wakefulness assertion and does not request Accessibility permission or create synthetic input.

## Features

- Prevent display sleep during active sessions.
- Timed session presets for presentation, monitoring, focus, and reduced-interaction workflows.
- Custom session duration controls.
- Optional indefinite sessions with an explicit safety setting.
- Keyboard-accessible controls window.
- Menu bar quick access for status, start/stop, and reopening the controls window.
- High contrast-friendly controls.
- VoiceOver-friendly labels, hints, and status text.

## Accessibility

AwakeBar is designed around standard macOS controls and keyboard navigation:

- Tab and Shift-Tab move through controls.
- Space activates the highlighted control.
- Arrow keys adjust presets and custom duration controls.
- Command-0 opens the AwakeBar Controls window.
- Command-W hides the Controls window.

AwakeBar does not use Accessibility APIs and does not require Accessibility permission.

## Privacy

AwakeBar does not collect, store, transmit, or share personal data. All functionality runs locally on the user's Mac.
