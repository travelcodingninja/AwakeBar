# AwakeBar

AwakeBar is a lightweight macOS menu bar utility that helps maintain uninterrupted workstation sessions during presentations, focus sessions, monitoring tasks, streaming, and accessibility workflows.

## Features

- Prevent display sleep
- Optional gentle cursor support
- Accessibility-friendly controls
- Lightweight native macOS utility
- Menu bar quick access

## Privacy

AwakeBar does not collect or transmit personal data.
